## Alur bisnis

Alur utama dimulai dari pelanggan dan penawaran. Setelah disetujui, proyek mencatat anggaran, progres, tim, dan linimasa. Pesanan pembelian kepada pemasok diterima ke inventaris; pengeluaran dan pembatalan stok ditulis melalui StockService serta dapat dibebankan ke proyek. Faktur dan pembayaran sebagian menutup siklus komersial, sementara biaya melalui gerbang persetujuan.

## Pelaporan dan akses

ReportController menyusun query terkelompok untuk ringkasan keuangan, kinerja proyek, valuasi inventaris, kinerja karyawan, dan analisis pelanggan. Setiap modul memerlukan autentikasi. Gate `approve` membatasi persetujuan penawaran, penerimaan pesanan pembelian, dan persetujuan biaya bagi peran admin serta manager. Layar daftar memakai filter query string dan pagination sehingga tautan tetap dapat dibagikan.

## Catatan implementasi

Antarmuka memakai sistem desain CSS sendiri dengan JavaScript kecil berbasis atribut data untuk sidebar, tab, dialog, dan editor rincian barang. Layar inti tetap berfungsi tanpa skrip sisi klien. Repositori memiliki pengujian PHPUnit serta skrip Playwright untuk menangkap tangkapan layar dan memeriksa tata letak pada 1920, 1366, 768, dan 390 px.

Tangkapan layar di halaman portofolio ini berasal dari data demo hasil seeder, bukan database perusahaan langsung. Tidak ada demo daring yang ditautkan untuk proyek ini.
