## Alur data dan permintaan

Skema menyimpan film, acara TV, musim, episode, pemeran, genre, tag, trailer, dan unduhan di tabel lokal. Controller publik merender halaman katalog dan detail; controller admin menulis ke tabel yang sama di balik middleware `auth`, `verified`, dan peran `admin`.

`TmdbService` menjadi satu-satunya klien untuk permintaan TMDB. Layanan ini lebih mengutamakan token akses baca v4 yang dikirim sebagai header bearer dan memakai kunci v3 bila token tidak tersedia. Respons disimpan dalam cache dengan TTL yang dapat diatur, sehingga permintaan Explore dan tren tidak memanggil API pada setiap pemuatan halaman.

## Dua jalur data

Metadata hasil impor tersimpan di MySQL dan dapat dikelola dari panel admin. Halaman Explore membaca TMDB saat permintaan dan menyimpan respons hanya di cache sementara. Pemisahan ini membuat suntingan admin tidak tertimpa oleh proses penyegaran, sementara Explore tetap dapat menampilkan judul terkini tanpa menambah data lokal.

Repositori mendokumentasikan instalasi lokal berbasis Docker dengan Laravel, Vite, dan MySQL. Tidak ada demo daring yang ditautkan untuk proyek ini.
