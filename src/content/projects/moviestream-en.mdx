## Data and request flow

The schema stores movies, TV shows, seasons, episodes, cast, genres, tags, trailers, and downloads in local tables. Public controllers render catalog and detail pages; admin controllers write to the same tables behind `auth`, `verified`, and `admin` role middleware.

`TmdbService` is the single client for TMDB requests. It prefers a v4 read access token sent as a bearer header and falls back to a v3 key when no token is configured. Responses are cached for a configurable TTL, so repeated Explore and trending requests do not call the API on every page load.

## Two data paths

Imported metadata is persisted in MySQL and can be curated from the admin panel. Explore pages read TMDB at request time and keep responses only in the temporary cache. Keeping the paths separate means admin edits are not overwritten by a refresh, and Explore can show current titles without growing the local database.

The repository documents a Docker-based local setup with Laravel, Vite, and MySQL. No hosted demo is linked for this project.
