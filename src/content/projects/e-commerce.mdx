## Alur belanja

Storefront membaca katalog dari API dan menyimpan filter pada URL. Keranjang tamu berada di Redux; setelah login, isinya disinkronkan ke keranjang server. Checkout hanya mengirim ID produk dan jumlah. API memuat ulang harga, menghitung ongkos kirim dan pajak, membuat pesanan berstatus menunggu pembayaran, mereservasi stok secara atomik, lalu mengarahkan browser ke Stripe Checkout. Webhook bertanda tangan menyelesaikan pesanan, sementara pembatalan dan kedaluwarsa melepaskan reservasi satu kali dan mengembalikan keranjang.

## Status yang dimiliki server

Autentikasi JWT dan peran admin menjaga endpoint sensitif. Perubahan produk, penyesuaian inventaris, status pesanan, dan analitik hanya tersedia untuk admin. Reservasi memakai pembaruan bersyarat pada stok tersedia di dalam transaksi MongoDB, dan setiap penyesuaian tercatat sebagai pergerakan stok yang hanya bisa ditambah. ID event webhook disimpan dengan status pemrosesan sehingga pengiriman duplikat tidak dapat mengubah pesanan dua kali.

## Operasional dan batasan

Docker Compose menjalankan frontend, API, dan MongoDB single-node replica set dengan healthcheck serta volume persisten. Repositori menyertakan pengujian integrasi Jest, pengujian komponen Vitest, data seed, dokumentasi arsitektur dan API, serta tangkapan layar desktop dan mobile. Checkout memerlukan kunci uji Stripe dan penerusan webhook, sehingga tidak ada demo daring yang ditautkan; tangkapan layar memakai data seed sintetis.
