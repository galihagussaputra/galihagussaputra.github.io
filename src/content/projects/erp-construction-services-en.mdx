## Business workflow

The main path starts with a customer and a quotation. After approval, a project records its budget, progress, team, and timeline. Purchase orders to suppliers are received into inventory; stock issues and reversals are written through StockService and can be attributed to a project. Invoices and partial payments close the commercial cycle, while expenses pass through an approval gate.

## Reporting and access

ReportController builds grouped queries for the financial summary, project performance, inventory valuation, employee performance, and customer analysis. Authentication is required for every module. The `approve` gate limits quotation approval, purchase-order receiving, and expense approval to admin and manager roles. List screens use query-string filters and pagination, so views remain linkable.

## Implementation notes

The interface is a custom CSS design system with small data-attribute driven JavaScript for the sidebar, tabs, dialogs, and line-item editor. Core screens still work without client-side scripting. The repository includes PHPUnit tests plus Playwright scripts that capture screenshots and check layouts at 1920, 1366, 768, and 390 px.

The screenshots on this portfolio page come from the seeded demo dataset, not from a live company database. No hosted demo is linked for this project.
